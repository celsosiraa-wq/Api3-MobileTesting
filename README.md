# Actividad Práctica Integradora 3 - Mobile Testing

## Objetivo

Consultar una API utilizando Kotlin, obtener un listado de productos y mostrar sus nombres y precios.

## API utilizada

https://jsonkeeper.com/b/MX0A

## Archivos del proyecto

- Main.kt: código principal.
- build.gradle.kts: configuración y dependencias.
- settings.gradle.kts: nombre del proyecto.
- README.md: descripción de la actividad.

## Ejecución

El proyecto puede ejecutarse utilizando IntelliJ IDEA con Gradle.

## Resultado esperado

Visualizar el nombre, la moneda y el precio de los productos obtenidos de la API.
